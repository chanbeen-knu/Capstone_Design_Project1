# 온톨로지 챗봇 평가

```bash
backend/.venv/Scripts/python experiment/run.py                                   # 개발 세트 40문항
backend/.venv/Scripts/python experiment/run.py --file questions_holdout.csv --repeat 3   # 검증 세트 22문항
```

- 채점: ① 질문 이해(유형·조건 노드 ID, 허용하지 않은 노드가 섞이면 실패) ② 조회 정확도(기대 사실·근거 사례) ③ 숫자 근거(문장 속 숫자가 조회 결과에 있는가)
- 기대값은 챗봇 코드와 별개로 쓴 Cypher로 계산 (Aura 건설업 3,459건, 2026-11-25)
- 답변 문장 형식은 채점하지 않음

## 결과 (3회 반복)

| 세트 | 문항 | 모든 층 통과 (문항 기준) | 결과 파일 |
|---|---|---|---|
| 개발 세트 `questions.csv` — 수정 전 | 40 | 34/40 | `summary_ontology_20261125_0922.md` (1회, 느슨한 채점) |
| **검증 세트** `questions_holdout.csv` — 코드 고정 | 22 | **20/22** | `summary_ontology_holdout_20261125_0940.md` |
| 검증 세트 — 결함 수정 후 | 22 | 22/22 | `summary_ontology_holdout_20261125_1656.md` |

- **논문·발표에 쓸 성능 값은 코드를 고정하고 측정한 검증 세트 20/22 (91%)**. 수정 후 값은 결함이 해결됐는지 확인용.
- 검증 세트도 챗봇 구조를 아는 사람이 썼으므로, 팀원이 새로 쓴 문항으로 한 번 더 검증 권장.
