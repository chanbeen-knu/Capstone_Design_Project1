- 프로젝트 소개: 배경·목표·기능·구조·계획. 발표 모드에서 메뉴 숨김, Esc로 복귀.

- 900px 이하: 메뉴와 보조 채팅을 접고 상단 버튼으로 열기.

## 원본 데이터
`public/data/cases.json`은 제공된 SIF 엑셀의 제조업 등 2,573개 행과 건설업 3,459개 행에서 생성한 6,032개 기록이다. 원본 중복을 임의로 제거하지 않았다. 숫자 연번을 가진 행만 수집하며 개요 및 헤더 행은 제외한다. 각 시트의 고유 열과 값을 fields에 보존하고 파일명·시트명·행을 추적한다. 원본 파일은 변경하지 않는다.

다시 생성: openpyxl이 설치된 Python으로 `python scripts/import_cases.py '/path/to/source.xlsx'` 실행.
제조업의 작업 상황과 건설업의 작업명, 제조업 대분류와 건설업 공종은 조회 필터에서만 대응시키며 상세에는 본래 명칭을 표시한다. 발생일이나 재해종류를 본문에서 임의로 추정하지 않는다.

## 연동 경계
FastAPI와 Gemini 채팅을 연결하고 main의 Neo4j 그래프 API를 유지한다. 사고 사례 목록은 정적 JSON으로 로드하며 caseRepository를 API로 교체 가능하다. 채팅은 아직 온톨로지 기반 답변이 아니며, 실제 근거 사례 ID가 없으므로 임의의 근거 링크를 표시하지 않는다. 기사·평가 수치는 아직 추가하지 않는다.

main 통합 후 빌드·린트·Python 구문 검사를 통과했다. 로컬 Neo4j 인증 정보가 맞지 않아 실제 그래프 조회는 검증하지 못했으며, DB 데이터나 인증 설정은 변경하지 않았다.
