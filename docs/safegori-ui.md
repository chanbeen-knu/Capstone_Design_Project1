- 안전대책 물어보기: 전용 채팅 화면과 최근 대화 저장·재열기, 생성 중단, 메시지 복사.
- 사고 사례 조회: 정규화된 키워드 검색, 필터, 45건 단위 페이지, 상세 원문 및 사고 패턴. 원문에서 돌아오면 기존 패턴 상세를 유지.
- 프로젝트 소개: 배경·목표·기능·구조·계획. 발표 모드에서 메뉴 숨김, Esc로 복귀.
- 설정: 화면 테마·글자 크기·그래프 표시·답변 표시·출처 표시, 전체 대화 삭제 및 Upstage/Neo4j 연결 상태.
- 1050px 이하: 상단 버튼으로 주 메뉴 열기. 900px 이하에서는 온톨로지 탐색 메뉴와 그래프를 세로 배치.
- 그래프 전체보기: 브라우저 fullscreen API와 viewport fallback을 사용하며 종료 시 버튼으로 포커스 복귀.

## 원본 데이터
`public/data/cases.json`은 제공된 SIF 엑셀의 제조업 등 2,573개 행과 건설업 3,459개 행에서 생성한 6,032개 기록이다. 원본 중복을 임의로 제거하지 않았다. 숫자 연번을 가진 행만 수집하며 개요 및 헤더 행은 제외한다. 각 시트의 고유 열과 값을 fields에 보존하고 파일명·시트명·행을 추적한다. 원본 파일은 변경하지 않는다.

다시 생성: openpyxl이 설치된 Python으로 `python scripts/import_cases.py '/path/to/source.xlsx'` 실행.
제조업의 작업 상황과 건설업의 작업명, 제조업 대분류와 건설업 공종은 조회 필터에서만 대응시키며 상세에는 본래 명칭을 표시한다. 발생일이나 재해종류를 본문에서 임의로 추정하지 않는다.

## 연동 경계
FastAPI와 Upstage 채팅을 연결하고 main의 Neo4j 그래프 API를 유지한다. 사고 사례 목록은 정적 JSON으로 로드하며 caseRepository를 API로 교체 가능하다. 채팅은 아직 온톨로지 기반 답변이 아니며, 실제 근거 사례 ID가 없으므로 임의의 근거 링크를 표시하지 않는다. 기사·평가 수치는 아직 추가하지 않는다.

`npm run build`, `npm run lint`, `node --test tests/conversation-search.test.js` 통과.
브라우저에서 실제 Neo4j 그래프, 전체보기 진입/종료, 사례 검색(PLC 위치센서), 패턴 대표 사례→원문→패턴 복귀, 390px 모바일 탐색, 다크모드, 사이드바 접기와 그래프 크기 조정 확인. 브라우저 오류 없음.
Upstage 키 설정/미설정, 대화 기록 전달, 공급자 오류 응답과 온톨로지 라우트는 모의 HTTP 테스트로 검증. 실제 Upstage 호출과 브라우저에서 생성 중 대화 전환·삭제는 이번 통합에서 검증하지 않음.
