# SafeGori 가독성 및 설정 개선

- 사용자 요청에 따라 PNG 로고 적용을 취소하고 상단 기본 아이콘과 SafeGori 텍스트, 하단 S 아바타를 사용.
- `safegori.preferences`에 검증된 화면 설정만 저장. 대화 내용과 API 키는 저장하지 않음.
- 설정 화면은 넓은 화면을 사용. 채팅·그래프·사례 화면 인스턴스를 유지하여 입력과 검색 상태 보존.
- 대화는 별도 `safegori.conversations.v1` 키에 저장. 전체 대화 삭제나 대화 전환 시 ChatPanel을 새로 마운트하고 AbortController로 이전 요청을 취소. 서버 측 이미 시작된 Upstage 작업은 완료될 수 있음.
- `/api/health`의 `upstage_configured`는 키 값 없이 설정 여부와 현재 서버 프로세스의 최근 Upstage 응답 성공 시각 제공. 상태 조회로 새 Upstage 요청을 보내지 않음.
- 출처 표시 토글은 표시만 제어. 사고 데이터 값은 변경하지 않음.
- 출처가 확정되지 않은 사고 통계는 소개 화면에 사용하지 않음. 정보 탐색·연결 부담 완화라는 목표 반영.

검증 (2026-10-18 통합): 빌드·린트·대화/검색 유틸리티 테스트 통과. 브라우저에서 Upstage 키 미설정 상태, Neo4j 연결 상태, 다크모드 및 모바일 탐색 확인. 실제 Upstage 호출은 하지 않았으며, 키 설정/미설정·대화 기록 전달·오류 응답은 모의 HTTP 테스트로 확인.
