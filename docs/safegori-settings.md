# SafeGori 가독성 및 설정 개선

- 사용자 요청에 따라 PNG 로고 적용을 취소하고 상단 기본 아이콘과 SafeGori 텍스트, 하단 S 아바타를 사용.
- `safegori.preferences`에 검증된 화면 설정만 저장. 대화 내용과 API 키는 저장하지 않음.
- 설정 화면은 넓은 화면을 사용. 채팅·그래프·사례 화면 인스턴스를 유지하여 입력과 검색 상태 보존.
- 대화 삭제 시 AbortController와 대화 세대 번호로 이전 요청의 응답 추가 방지. 서버 측 이미 시작된 Gemini 작업은 완료될 수 있음.
- `/api/health`는 키 값 없이 설정 여부와 현재 서버 프로세스의 최근 Gemini 응답 성공 시각 제공. 상태 조회로 새 Gemini 요청을 보내지 않음.
- 출처 표시 토글은 표시만 제어. 사고 데이터 값은 변경하지 않음.
- 출처가 확정되지 않은 사고 통계는 소개 화면에 사용하지 않음. 정보 탐색·연결 부담 완화라는 목표 반영.

검증: 빌드, 린트, diff 검사 통과. 브라우저에서 설정 저장/새로고침, 다크모드, 글자 크기, 그래프 설정과 검색 유지, 생성 중 대화 삭제/취소, 입력 유지, 출처 토글, 서비스 상태, 발표 모드 종료 확인. 브라우저 콘솔 오류 없음.
